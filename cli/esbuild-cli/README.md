# @noodlestan/esbuild

> A small opinionated wrapper around `esbuild` used by Noodlestan packages.

## Usage

```json
"scripts": {
  "build": "noodlestan/esbuild-cli",
  "watch": "noodlestan/esbuild-cli-watch"
}
```

### Build targets

This library is NOT built.
